# docs/research/

Research notes that back the skill's prompted option lists and the renderer's layout rules.

- [`threat-attributes.md`](threat-attributes.md): **done 2026-10-23.** STRIDE and LINDDUN with prompt wording; ATT&CK v20 tactics; adversary profile options (STIX types + NB additions, NIST source classes, motivation, capability, intent, targeting, resources, privileges, access vector); both risk methods with the user-facing comparison, full option values and the band mapping; CVSS; reference-ID patterns and current OWASP lists; ISO 27005 treatments; control types, statuses and verification; threat status lifecycle; what was not adopted and why.

- [`service-flow-threat-attributes.md`](service-flow-threat-attributes.md): **done 2026-10-24.** Service profile options (ownership, platform, location, device authentication per NIST 800-63B, elevated access per Microsoft's enterprise access model, patching per NIST 800-40r4 / CISA KEV, hardening baselines CIS / STIG, sourcing per FAR COTS), flow detail (connection, data types, sensitivity labels NPI / CUI / FCI / MNPI / PII / TLP, transport security properties, client and server authentication, credential storage ranked per OWASP), threat vulnerability categories (CWE / OWASP Top 10:2025), threat statement template, as-is / future controls, scope.
- [`cloud-service-catalogue.md`](cloud-service-catalogue.md): **done 2026-10-24.** Method, the recent default changes that matter (S3 ACLs/Block Public Access, IMDSv2, Azure anonymous blob access, App Service basic auth, GCS public access prevention), cross-provider patterns (private connectivity, workload identity, metadata services, admin brokers, perimeters, logging), the misconfigurations the threats encode, and sources for the 36 cards in `references/cloud/`.
- [`layout-routing.md`](layout-routing.md): **done 2026-10-25.** What the evidence says makes a diagram readable (crossings, then bends), the layered placement pipeline and how the model maps onto it, optimal orthogonal connector routing (visibility graph, A\* over node and heading, nudging) with the penalty values tools use, the domain conventions for DFDs and architecture diagrams, the precedence model H1–H4 / S1–S6 the renderer now follows, and what changed in renderer 1.6.0.

Each note ends with a Sources list. The option lists are then copied into `skills/netblueprint-forge/references/threats.md` and `risk-scoring.md` and into the schema enums.
