# Contributing

NetBlueprint Forge is written and maintained by DigitalPrez, LLC alone. Reports are welcome; code is not. This page says what that means in practice.

## Bug reports and feature requests: yes

Open an issue with one of the two forms: a [bug report](https://github.com/digitalprezllc/netblueprint-forge/issues/new?template=bug_report.yml) for something the skill, a script or a rendered page does wrong, a [feature request](https://github.com/digitalprezllc/netblueprint-forge/issues/new?template=feature_request.yml) for something you wish it did. Describe the behaviour or the need; the fix or the design is ours to write. The version, the command or the step, what you expected and what you saw are usually enough for a report. Keep real names, addresses and anything else from a real model out of it: the models in `examples/` make a fine stand-in, and an issue is visible to everyone who can see the repository.

A question about using the skill is welcome the same way: as a bug report when something did not work, as a feature request when the documentation left a gap. The answer usually becomes a line in the documentation.

## Pull requests: no

Pull requests are not accepted. A workflow closes any that is opened from outside the organization, with a note, and nothing from one is reviewed, merged or kept. Code pasted into an issue is treated the same way: the issue is read for the problem it describes, not for the patch.

The reason is the licence. NetBlueprint Forge is source-available under the PolyForm Noncommercial License with DigitalPrez's additional terms, and organizations use it for business under a commercial licence from DigitalPrez, LLC. Every line being ours keeps that simple: there is no contributor agreement to sign, and nobody has to wonder who owns what. An issue that describes a problem well gets the same fix a pull request would have brought, written here.

## Security problems

Not as an issue. [SECURITY.md](SECURITY.md) says how to report one privately.

## Everything else

Licensing questions and commercial licences: subscriptions@digitalprez.com. The models you write and the diagrams rendered from them are yours (the output exception in [LICENSE](LICENSE)); there is nothing to send back.
